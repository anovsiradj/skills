# Import Workflow
Managing how external files are converted for Godot.

### Steps
1. **Place Asset**: Drop your `.png`, `.glb`, or `.wav` into the `res://` folder.
2. **Configure**: 
   - Select the file in **FileSystem**.
   - Go to the **Import Tab** (next to the Scene tab).
   - Change settings (e.g., change a texture to "Compress Mode: Lossless").
3. **Reimport**: Click the **Reimport** button to apply changes.

### Bulk Import
To change settings for many files at once:
1. Select multiple files in FileSystem.
2. Adjust settings in the Import Tab.
3. Click Reimport.
