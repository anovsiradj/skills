# Version Control Tips

### `.import` Files
- **Description**: `.import` files contain import settings for assets, such as textures, models, and animations.
- **Tip**:
  - **Add to Version Control**: Commit these to Git. They store your import settings (like texture compression). If you delete them, everyone on your team will have different import settings.
  - **Backup**: Keep backups of `.import` files in case of accidental changes.
  - **Documentation**: Document import settings for team members.

### `.godot/` Directory
- **Description**: The `.godot/` directory contains project-specific files like `.import`, `.export_presets`, and `.scene` files.
- **Tip**:
  - **Exclude from Version Control**: Add `.godot/` to your `.gitignore` file. It is massive and is automatically regenerated by the engine on every machine.
  - **Backup**: Regularly back up important `.godot/` files.

### Export Presets
- **Description**: Export presets define settings for exporting projects to different platforms.
- **Tip**:
  - **Version Control**: Store export presets in version control for consistency.
  - **Documentation**: Document export preset configurations for team members.
  - **Testing**: Test export presets on different platforms to ensure compatibility.

### Reimporting
- **Description**: If you edit a file in an external program (like Photoshop), Godot detects the change via checksum and reimports it automatically.
- **Tip**:
  - **Manual Reimport**: Use `Project > Reimport` to manually reimport assets.
  - **Batch Reimport**: Use `Project > Batch Reimport` to reimport multiple assets at once.
  - **Checksums**: Ensure checksums are updated correctly for accurate reimports.
