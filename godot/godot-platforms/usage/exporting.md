# Exporting Your Game
Exporting is the process of turning your project into a playable application.

### Workflow
1. **Setup Templates**: Go to `Project` -> `Export` -> `Manage Export Templates` and ensure templates are downloaded.
2. **Add Preset**: Click `Add...` and select your target platform (e.g., Windows Desktop).
3. **Configure**: Set the application name, icon, and permissions (critical for Android/iOS).
4. **Export**: Click `Export Project` and choose a save location.

### Platform Specifics
- **Android**: Requires Android Studio and the SDK path to be set in `Editor Settings` -> `Export` -> `Android`.
- **iOS**: Requires a Mac with Xcode.
- **Web**: Export as HTML5. Use the **Compatibility** renderer.
