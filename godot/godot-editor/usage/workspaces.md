# Using the Editor Workspaces
Godot provides specialized views for different tasks.

### 2D View
Used for Sprite placement, UI layout, and 2D level design.
- Use the **Grid Snap** to align objects perfectly.
- Use **Layers** in TileMaps for depth.

### 3D View
Used for environment building and lighting.
- Use **Focus Selection** (F key) to snap the camera to an object.
- Use **Vertex Snapping** for precise mesh placement.

### Script Editor
The built-in IDE for GDScript.
- **F1**: Search API documentation instantly.
- **Ctrl+Click**: Jump to a function or class definition.
